# Лендинг EastWood

Статичный сайт: все файлы лежат в одной папке, без вложенных. Ничего не нужно собирать.

## Как выложить на GitHub Pages
1. Создайте на github.com новый публичный репозиторий, например `eastwood`.
2. Нажмите **Add file → Upload files** и выделите все файлы этой папки (Cmd+A / Ctrl+A) и перетащите их разом. Нажмите **Commit changes**.
3. Откройте **Settings → Pages**. В поле **Source** выберите **Deploy from a branch**, ветка **main**, папка **/ (root)**, нажмите **Save**.
4. Через 1–2 минуты сайт откроется по адресу `https://ВАШ-ЛОГИН.github.io/eastwood/`.
